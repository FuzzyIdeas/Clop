## Fixes

- Watched folders are no longer deleted from the list when the folder can't be found. A folder on an unmounted volume, or one that only exists on another Mac, is skipped until it comes back instead of being forgotten
- A missing watched folder no longer stops every other watched folder from being watched
- Downscaling a video from a pipeline step no longer leaves it at the original resolution
- Converting a file in place no longer leaves the original behind
- PNG converted to JPEG by adaptive compression no longer leaves the PNG behind when saving to the same folder with a name template
- No more freeze when a bundled tool or a pipeline script prints a lot of output
- Fixed a possible freeze while copying a file to its save location
- No more temporary folder left behind on every optimisation
