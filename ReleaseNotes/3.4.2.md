## Features

- **Pipeline buttons** on floating and compact results: pick a saved pipeline from the *Pipelines* submenu of the add button, then click its icon to run it on that file
    > Assign them in Settings or straight from the `+` slot on a floating result
    >
    > One button can hold a pipeline for each file type, so the same slot runs your image pipeline on images and your video pipeline on videos. Click a pipeline button in Settings to choose them

## Improvements

- Pipeline menus show each pipeline's icon next to its name and description, grouped by file type
