## Features

- **MCP server** lets an AI agent drive Clop in plain language: optimise and convert files, write pipelines, and read or change any setting. Needs Clop Pro
    > Install it into Claude Code, Claude Desktop, Cursor, VS Code, Windsurf or Zed from Settings, MCP. One entry is added to the agent's own config file and everything else in it is left alone
    >
    > Nothing is allowed until you switch it on, and it stays on until you switch it off. Script steps in agent-written pipelines are behind a second switch of their own
    >
    > Ask "why is Clop not replacing the mov with the optimised mp4" and the agent finds the setting that answers it

- **Search the Settings window**: type what you want to change instead of hunting for the pane it lives in
    > Searches titles, descriptions and a hand-written list of the words people actually use, so "gps" finds EXIF stripping and "make videos smaller" finds the compression tier

## Fixes

- Holding `⌥` or `⌃` while dragging no longer toggles the drop zone or the preset zones, only a tap does
- Tapping `⌃` while the drop zone is hidden no longer leaves the preset zones pinned open, so the drop zone stops reappearing straight into them with a mirrored icon

## Improvements

- Videos converted automatically for compatibility replace the original instead of leaving a copy beside it. Existing setups keep the placement they already use
- `clop settings` reads and changes any setting from the command line, with a plain-language search: `clop settings schema "replace the original"`
